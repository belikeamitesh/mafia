# Mafia Night

Online Mafia for friends: create a room, share the link, get a secret role, chat, vote.

Run locally: `npm install && npm start` → http://localhost:3000. Rule checks: `npm test`.

## Free hosting (Render)
1. Push this folder to a GitHub repo.
2. On https://render.com → New → Blueprint → pick the repo (it reads `render.yaml`).
3. Share `https://<your-app>.onrender.com`. Free instances sleep after 15 min idle; the first visit takes ~50s to wake.
